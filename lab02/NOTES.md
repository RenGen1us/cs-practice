- Рабочая папка (Working Directory) — файлы, с которыми ты сейчас работаешь и которые можешь изменять.
- Индекс (Staging Area) — изменения, которые ты подготовил для следующего коммита через git add.
- Коммит (Commit) — сохранённый снимок подготовленных изменений в истории Git.

Git — система контроля версий. Работает локально на компьютере и отслеживает изменения в коде.
GitHub — онлайн-платформа, где можно хранить Git-репозитории, делиться кодом и работать над проектами вместе c другими людьми.

## Использованные команды
- git status — показывает общее состояние репозитория: какие файлы изменены, какие добавлены в staging, а какие ещё нет.
- git diff — показывает сами изменения, которые ещё не добавлены в staging.
- git diff --staged — показывает сами изменения, которые уже добавлены в staging и попадут в следующий commit.

## Ветки
- Ветка (branch) — это отдельная линия разработки проекта. Она позволяет менять код независимо от других веток.
- Новый commit добавляется в текущую ветку и продолжает её историю.
- Слияние (merge) объединяет изменения одной ветки с другой.
